# Version Notes

This scaffold targets the current Framer plugin package line used during implementation.

- `@framer/plugin`: 5.1.x
- `vite-plugin-framer`: 1.1.x

Framer renamed the old `framer-plugin` package to `@framer/plugin` in 2026. Keep the package names aligned with the current SDK when upgrading.

The generated widget is installed through Framer's `bodyEnd` Custom Code API.
